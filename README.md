Extract this archive into the root of a GitHub repository. Use GitHub Desktop or git to commit and push all files (the media are large). In Settings > Pages select Deploy from a branch, main, / (root).

Their visual fidelity and animation behavior have not been verified in a browser. The original runtime and local assets are retained; external links remain external.
